# Fantasy Incremental（仮）

ファンタジー世界を舞台にした、アクション×インクリメンタルゲームの試作です（Godot 4）。

- 試遊（Web版）: https://elefolo4565.github.io/fantasyIncremental/

## 試作の遊び方

1. 魔導樹（Magic Tree）の画面で START RUN を押すと、ランが始まります。最初の活動時間は15秒で、強化の Hourglass で伸びます。最初の魔法弾は遅く、射程も短く、威力も弱いので、Quick Cast・Far Sight・Bolt Power で育てます。
2. 左半分をドラッグして移動（PC は矢印キー / WASD）。魔法弾は近くのモンスターや木へ自動で飛びます。
3. モンスター（スライム）は歩き回り、近づくと寄ってきます。触れると体力が減り、0 になるとそこでランが終わります（集めた素材は残ります）。
4. 決まった数の敵を倒すとボスが出ます。ボスを倒すとステージクリアで、次のステージが解放されます。
   倒した敵は宝石・木材を落とすので、近づいて拾ってください（魔導樹の「引き寄せ」で拾える範囲が広がります）。
5. 集めた宝石（Gem）と木材（Wood）で魔導樹の強化を覚えると、必要な発数が減ったり、攻撃の挙動が変わったりします。

ステージは平原（Plains）1〜3 と森（Forest）1〜3 の6つです。森の木は叩かずにいると耐久が戻ります。
進み具合はブラウザに保存されます。最初からやり直すときは左下の Reset save を2回押します。

## 数値の調整

| ファイル | 中身 |
| --- | --- |
| `data/balance.csv` | 活動時間、体力、移動速度、攻撃間隔、スライムの動きの共通の数値 |
| `data/stages.csv` | ステージごとのスライム・木の数と耐久、スライムの速さ、ごほうび、ボスが出るまでの数とボスの耐久・ごほうび・速さ |
| `data/upgrades.csv` | 魔導樹の強化ノード（効果量、段ごとの費用、画面上の位置、説明文） |
