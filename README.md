# Fantasy Incremental（仮）

ファンタジー世界を舞台にした、アクション×インクリメンタルゲームの試作です（Godot 4）。

- 試遊（Web版）: https://elefolo4565.github.io/fantasyIncremental/

## 試作の遊び方

1. 魔導樹（Magic Tree）の画面で START RUN を押すと、60秒のランが始まります。
2. 左半分をドラッグして移動（PC は矢印キー / WASD）。魔法弾は近くの岩や木へ自動で飛びます。
3. 岩や木に出ている数字は「あと何発で壊れるか」です。目標の数を壊すと次のステージが解放されます。
4. 集めた石（Stone）と木材（Wood）で魔導樹の強化を覚えると、必要な発数が減ったり、攻撃の挙動が変わったりします。
5. 壊すたびに精霊の輪（Spirit Ring）のゲージがたまり、ランの間だけ玉が増えていきます。

ステージは平原（Plains）1〜3 と森（Forest）1〜3 の6つです。森の木は叩かずにいると耐久が戻ります。
進み具合はブラウザに保存されます。最初からやり直すときは左下の Reset save を2回押します。

## 数値の調整

| ファイル | 中身 |
| --- | --- |
| `data/balance.csv` | 移動速度、攻撃間隔、精霊の輪などの共通の数値 |
| `data/stages.csv` | ステージごとの岩・木の数と耐久、ごほうび、目標数、制限時間 |
| `data/upgrades.csv` | 魔導樹の強化ノード（効果量、段ごとの費用、画面上の位置、説明文） |
